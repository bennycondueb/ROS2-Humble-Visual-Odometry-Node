# ROS 2 Humble Visual Odometry Node

## Description

A **stereo visual-odometry** node that estimates yaw from synchronized left and
right camera images using **ORB feature matching** and publishes the result for
ROS 2 consumers.  

This Node has been developed during my time as a **Software Developer** in _Squadra Corse Driverless PoliTo_, and was meant to be a package inside our in-house Simulator.  
It's **not** meant to be run as a standalone node.  
But the latter could be a nice future project.
